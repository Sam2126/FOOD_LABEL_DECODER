Food Label Decoder Pipeline Workflow

This application implements a complete end-to-end Retrieval-Augmented Generation system. Food labels are split into constituent ingredients, embedded into 384-dimensional dense vectors using MiniLM, and matched against curated Codex Alimentarius and FDA records via FAISS cosine similarity search.

Microservices Overview:
• Application Service (Port 8000): Public orchestrator & UI server.
• RAG Service (Port 8001): FAISS vector database queries & context formatting.
• LLM Service (Port 8002): High-performance Ollama gateway with model customization.
• Data Service (Port 8003): Ingestion, chunking, and persistent embedding generation.
