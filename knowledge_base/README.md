# Knowledge Base

This folder contains nutritional knowledge corpora, allergen databases, food additive classifications, and guideline documents used by the `retrieval_service` and `analysis_service`.

## Contents

- **Additives Registry**: E-number index, acceptable daily intake (ADI), and known adverse reactions.
- **USDA FoodData Central Index**: Nutritional reference profiles for standard ingredients and whole foods.
- **Allergen Rules**: FDA top 9 allergens and international regulatory labeling rules (e.g. EU FIC regulations).
- **Glycemic Index Database**: Glycemic index (GI) and glycemic load (GL) tables for common sweeteners and carbohydrates.
